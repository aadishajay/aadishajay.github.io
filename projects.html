pgapp

Postgres is the backend. This is everything else.

Point it at a Postgres database, describe what you need — a customer list, a helpdesk, an internal ops tool — in one plain-text file, and pgapp turns it into a real web app: data entry forms, searchable reports, charts, and user logins, plus a point-and-click editor for making changes without touching code. It's a solo project built from scratch in Rust, spanning the app's own text-based language, the web server, and the database layer — bringing the fast, all-in-one feel of Oracle APEX to something open-source and self-hosted.
